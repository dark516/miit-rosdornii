# Контроль транспорта при сбоях GNSS — этап 4 СМД
Откройте index.html в браузере. Интернет, установка и сервер не требуются. Выберите сценарий, перемещайте время, нажмите «Запустить». Скорость воспроизведения 5×; расчётный шаг 0,2 с (5 Гц модельного времени). CSV выгружает полный прогон.

## Эксперимент
Детерминированная компьютерная модель 120 с, скорость 8 м/с, переменный курс. Эталон интегрируется с шагом 0,02 с. Одометрия имеет масштабную ошибку +1%, гироскоп — смещение +0,00225 рад/с. Опорная коррекция каждые 10 с, погрешность координаты до 0,2 м по каждой оси. Модель GNSS имеет гармоническую погрешность до 0,4 м по оси. Интервал отказа 20–100 с включительно. Ложный GNSS смещён на (80,−60) м. Канал ИТС отключён 40–80 с.

Оцениватель интегрирует скорость и курс, затем применяет скалярное калмановское обновление координат. При ориентире курс выравнивается с эталонным: идеализированное допущение, которое требует проверки на реальных камерах. GNSS проверяется по невязке; порог max(5 м, 4√(P+0,25)). P увеличивается на 0,065 м² за шаг; это эвристическая модель неопределённости. Значение 2σ не гарантирует покрытие истинной ошибки. При 2σ>5 м выводится предупреждение.

Базовая траектория начинает отказ с той же оценки и курса, затем использует только одометрию/IMU. RMSE считается на 401 отсчёте 20–100 с, включая обе границы. Результаты относятся только к заданным условиям и не доказывают точность в реальном транспорте. Автотесты: node test.cjs. Результаты: results.json и CSV каждого сценария.

## Границы реализации
Работают расчёт, отбраковка скачка GNSS, состояния достоверности/связи, визуализация и экспорт. Реальная камера, детектор ориентиров, IMU/CAN, V2X, дорожная карта и транспорт не подключены. При одновременной потере опор дрейф растёт; восстановившийся GNSS может временно отклоняться до повторной привязки по ориентиру. Управление транспортом не реализовано.

Видео этапа прямо допускает компьютерную модель как эксперимент. Источники: официальный шаблон 4.3.pptx; видео 4.3.mp4, 00:57–03:27. Требования заказчика взяты из публичных ответов РОСДОРНИИ в MAX, использованных в этапе 2.
